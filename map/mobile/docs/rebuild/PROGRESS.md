## 발견된 사실 (재조사 불필요)

- **`MSPreds` 전역 충돌** — `draw-preds.js`(작도)와 `predictions.js`(기록)가 같은 이름. `chart-draw.js` 가 로드 시점에 캡처해 리포트가 100% 죽는다. → `MSPredDraw` / `MSPredLog` 로 개명(설계서 §4.5)
- **모듈 테스트는 전역 충돌을 볼 수 없다** — Node `require()` 는 모듈마다 독립 객체를 준다. 브라우저 관문이 유일한 방어
- **웹 실측값은 이미 앱 안에 있다** — `vendor/backtest-summary.js`. 기본 58.2%/콘 73.8%, 심화 58.5%/콘 77.1%, 전문 미측정
- **투자성향 프리셋 4종은 확보돼 있다** — `ind-tiers.js` `PRESETS`, 출처는 PC `forge-ui.js` `_PRESET_DEF`
- **차트 격차** — PC 31레이어(3,449줄) vs 모바일 6레이어(637줄). 미이식 목록은 `graph.js` 의 `MISSING`
- **시안 18b 라벨의 "블록 9개"는 오기** — 같은 아트보드 본문이 8개라고 적는다
- **포트 좀비 주의** — 2026-08-18 대조 때 전날 세션 서버가 8932 를 잡고 있어 새 mock 이 안 떴다
