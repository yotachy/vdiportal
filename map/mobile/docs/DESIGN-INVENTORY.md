## 3. 세 단계 격차 — 3단 비교표 (t18 원문 그대로)

| | 기본분석 (무료) | 심화분석 (3스쿱) | 전문분석 (5스쿱) |
|---|---|---|---|
| 가격 표현 | 종가 선 하나 | 캔들 + 거래량 바 | 심화와 동일 |
| 예측선 | 점선 한 줄, 범위 없음 | 1차 + 2차 + 80% 콘 | 심화와 동일 |
| 반대 시나리오 | 없음 | 3차 반대선 작도 | 심화와 동일 |
| 서브패널 | 없음 | RSI · MACD · 거래량 | 심화와 동일 |
| 차트 위 표식 | 없음 | 지지·저항 · 교차 · 다이버전스 | 심화와 동일 |
| 차트 높이 | 150 | 293 + 서브패널 120 | 심화와 동일 |

| 화면 정보 블록 | **3개** | **8개** | **9개**(심화 전부 + 조절판) |

**"기본을 일부러 초라하게 만들지 않는다"** — 선 하나로도 방향과 범위는 정확히 답한다. 다만 그 이상은
말하지 않는다. 쓸모없게 만들면 첫인상이 나빠지고, 충분하게 만들면 살 이유가 없다.
**"전문분석은 심화의 모든 블록을 유지한 채 조절판을 더한다"** — 한 줄이라도 빠지면 5스쿱 낸 사람이
손해다. 가중치 변경이 **공유 블록의 숫자를 실제로 바꿔야** 한다(반대 6→9개, 주기 일치 3중2→3중3 실증됨).

## 4. 막히는 상태 7종 (§1의 12c 표를 참조 — 요약)
