## 1. 왜 다시 시작하는가

2026-08-15~17 의 개편 라운드(P1·P2·"고리", 커밋 40여 개)는 **미완이 아니라 오작동**으로 끝났다. 감사에서 확인된 것:

1. **앱의 본체가 죽어 있다.** `draw-preds.js`(예측선 작도)와 `predictions.js`(예측 기록)가 둘 다 전역 `MSPreds` 를 등록하고, 뒤에 로드되는 쪽이 앞을 덮는다. `chart-draw.js` 가 로드 시점에 전역을 캡처하므로 리포트는 종목·티어와 무관하게 100% `MSPreds.seed is not a function` 으로 죽는다. 사용자가 설치한 APK(8/17 14:27)에 그대로 들어 있다.
2. **관문 1505건이 이것을 볼 수 없었다.** 모바일 테스트는 모듈을 Node 에서 `require()` 해 각각 독립 객체를 받는다. 브라우저 전역 하나를 두 파일이 다투는 사고는 원리적으로 관측 불가다. **실제 브라우저로 화면을 여는 관문이 하나도 없었다.**
3. **시안의 구조가 안 옮겨졌다.** 하단 탭바(목록·분석·스쿱)가 없어 앱의 뼈대가 개편 이전 그대로이고, 그래서 만든 화면들이 갈 곳이 없었다(마지막 커밋이 지갑에 임시 통로를 뚫어 때웠다).
4. **개편의 목적이 화면 밖으로 밀려났다.** 목적은 "사용자가 자발적으로 리워드 광고를 보게 만드는 것"인데, 리포트의 해제 CTA 가 `심화분석 보기` 라는 무광고 버튼으로 남았다.
5. **시각 언어가 텍스트로 납작해졌다.** 시안이 큰 수치·상태 아이콘·색으로 말하는 진행 점·마무리 문장으로 전달하는 판단을, 앱은 균일한 행으로 늘어놓아 무엇이 중요한지 화면이 말하지 않는다.

## 2. 목표 / 비목표

**목표** — 시안(턴 6~21) 전량을 앱으로 구현한다. 화면 33장 + 영어 UI + 폴드 2단·태블릿 3단 + 아이콘·스플래시. 차트는 **PC(스쿱포지) 품질**로 끌어올리되 티어별 차등을 유지한다. 시안의 샘플 수치는 **웹 실측값**으로 대체한다.

**비목표(이번 재시작에서 하지 않는 것)**

- 엔진(`forge-core.js`) 변경 — 작도·UI 전용 작업이다. 지표 추가·드리프트 변경 없음
- 서버 원장·AdMob SSV 재설계 — 개편 이전에 지어졌고 이번 실패와 무관
- 라이트 모드 — 다크 단독 유지(도입하면 차트 색 체계를 다시 정해야 한다)
- 실 AdMob 계정 연결·릴리스 서명 — 스토어 트랙이라 별건

## 5. 앱 셸 — 지금 없는 뼈대

현재 `app.js` 는 `if (state.showing === ...)` 사슬이고 탭바도 뒤로가기 스택도 화면 레지스트리도 없다. 시안이 요구하는 셸:

- **하단 탭 3개** — 목록(`watchlist`) · 분석(`report`, 마지막 종목) · 스쿱(`wallet`). 스쿱 탭은 **받을 것이 있을 때만** 배지가 켜진다
- **화면 레지스트리** — `{ id, tab, render(root, params), back }` 선언 → 라우터가 그린다. 화면 추가가 `if` 한 줄이 아니라 등록 한 줄이 되어야 한다
- **뒤로가기 스택** — 안드로이드 하드웨어 백 포함. 탭 전환은 스택을 쌓지 않고 탭별 스택을 유지
- **공용 하단 시트** — 상단 라운드 28 · 최대 82vh · 하단 안전영역. 단계 선택(6b)·종목 추가(12a)·성향 변경(12b)·광고 권유가 전부 이 컴포넌트를 쓴다
- **짧은 화면 대응** — 폴드 펼침 593 · 탭 640 에서 하단 탭바 → **68px 좌측 레일**(세로 62px 회수). P5 에서 구현하되 셸 구조는 P0 에서 그 전환을 받을 수 있게 만든다

## 8. 검증 — 이번 실패를 잡는 관문

### 8.1 3중 구조

| | 관문 | 무엇을 잡나 |
|---|---|---|
| 1 | 모듈 테스트 `./tests/run.sh` (기존 1505건 유지) | 계약·경계 |
| 2 | **브라우저 관문(신설)** | `MSPreds` 충돌 계열 — 모듈 테스트가 원리적으로 못 보는 것 |
| 3 | 단계별 APK + 사용자 실기기 확인 | 손맛 · 터치 타깃 · 성능 |

### 8.2 브라우저 관문 설계

**의존성 0** 으로 만든다(저장소 규율 — 빌드 도구 없음). 이미 있는 크로미움 바이너리(`~/.cache/ms-playwright/chromium-1228`)를 CLI 로 몬다.

- 각 라우트마다 **프로브 페이지**를 만든다: 상태를 `localStorage` 에 심고 → 앱을 부팅 → 해당 라우트로 이동 → 단언을 실행 → 결과를 `document.title` 에 `GATE:{json}` 으로 적는다
- `chrome --headless=new --enable-logging=stderr --dump-dom --screenshot` 한 번에 셋을 얻는다: **콘솔 로그(stderr)** · **단언 결과(title)** · **스크린샷**
- **실패 판정**: ① `CONSOLE` 에 `ERROR`/`SEVERE` 가 하나라도 있으면 실패 ② 단언 결과에 false 가 있으면 실패 ③ 전역 중복 등록(`globals.js` throw)은 ①로 잡힌다
- 스크린샷은 `mobile/docs/rebuild/shots/app-*.png` 를 갱신한다. 시안 쪽은 `tools/spec-shot.py` 가 뽑는다(`spec-*.png`)
- **포트 점검 필수** — `ss -lntp | grep <port>` 로 좀비 서버를 먼저 확인한다. 감사 때 전날 세션의 서버가 포트를 잡고 있어 새 mock 이 한 번도 안 떴다

### 8.3 지갑 서버를 건드리면

`./tests/run.sh concurrency` 를 반드시 함께 돌린다(`all` 에 안 낀다). 배포 세트는 `wallet-ssv.php` · `wallet-lib.php` · `wallet-api.php` 동반.

## 9. 수치·진실 규칙

### 9.1 실측값 단일 출처

모든 적중률·커버리지·ECE 는 `vendor/backtest-summary.js`(`window.MSBacktest`)에서만 읽는다. **리터럴 금지** — 관문으로 차단한다.

| | 방향 적중 | 콘 커버리지 | ECE | 자명 기준선 |
|---|---|---|---|---|
| 기본(5지표) | 58.2% | 73.8% | 1.05%p | 60.96% |
| 심화(32지표) | 58.5% | 77.1% | 0.27%p | 〃 |
| 전문 | **미측정 → "측정 중"** | — | — | — |

(엔진 v1.11.0 · 31,971 예측 · 87 시리즈)

### 9.2 시안 문구를 실측으로 교체

시안은 심화의 값을 "적중률 2%p 상승"으로 적었으나 실측은 **+0.4%p** 다(정정 2026-08-19 — P1a Task 4 리뷰 I2: `(0.585440515 − 0.581815834)×100` 을 반올림 전 원값으로 계산한 값. 위 §9.1 표의 이미 반올림된 두 값(58.5%−58.2%)을 그대로 빼면 +0.3%p 가 나오는데, 그건 이중 반올림 오차다 — 소스는 항상 원값(raw fraction)으로 차이·비율을 계산한 뒤 표시할 때만 반올림해야 한다, `map/mobile/www/tier-compare.js` 참고). **심화가 파는 것은 방향이 아니라 범위**다 — 콘 커버리지 73.8%→77.1%, ECE 1.05%p→0.27%p(4배 정밀). 화면 문구는 이 실측을 말해야 한다.

### 9.3 불변 규칙 (시안 README §핵심 설계 원칙)

1. 잔량을 낙관적으로 올리지 않는다 — 서버 SSV 확정 전에는 `+n 대기`
2. 못 준 값은 받지 않는다 — 판정 없음=미차감, 환불 미확인은 "돌려드렸다"고 말하지 않는다
3. 불리한 사실을 먼저 말한다 — 상한 폐기 고지는 **광고 전에**
4. 적중률은 엔진 전체 측정값이다 — 범위 주석(`rpHitScopeShort`) 필수
5. 표본 20건 미만이면 퍼센트를 쓰지 않는다
6. 막다른 골목 금지 — 막히는 상태 7종 전부에 다음 행동 버튼
7. 한 세션에 광고 권유 최대 2회, 거절하면 그 세션엔 다시 묻지 않는다
8. 로딩을 타이머로 흉내내지 않는다 — 캐시로 0.3초면 0.3초에 보여준다
9. 방향 적중률은 자명 기준선(60.96%) 병기 없이 단독 노출 금지
