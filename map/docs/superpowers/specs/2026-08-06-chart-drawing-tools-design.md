# 차트 드로잉 도구 — 설계

- 날짜: 2026-08-06
- 대상: `forge-tools.js`(신규) · `forge.html` · `forge.css` · `forge-app.js`(포인터 분기) · `forge-state.js`(저장)
- 상태: 설계 승인됨

## 1. 배경 · 목표

차트 위에 직접 선을 긋고 구간을 재는 수단이 없다. 트레이딩뷰를 참고해 **추세선·평행채널·등락폭 재기·기간 재기** 4종과 **마그넷** 모디파이어를 추가한다.

승인된 요구:
- 그림은 **종목별로 영구 저장**된다(서버). 다음에 열어도 그대로.
- **일/주/월 전환·줌·스크롤·로그↔선형**에도 같은 자리에 붙어 있어야 한다.
- 그린 뒤 **선택·통째 이동·끝점 조정·삭제**가 된다.

## 2. 앵커 모델 (린치핀)

그림의 점은 화면 좌표나 봉 번호가 아니라 **`(날짜, 가격)`**으로 저장한다.

```js
{ id:"d_ab12", type:"trend", a:{ t:"2026-03-14", p:288.5 }, b:{ t:"2026-08-05", p:345.0 } }
```

봉 번호로 저장하면 일→주 전환 시 봉 수가 약 1/5로 줄어 그림이 어긋난다. 날짜로 저장하면 렌더할 때마다 현재 `_times`에서 위치를 다시 찾으므로 주기·줌·축 전환을 자동으로 따라온다.

### 2.1 날짜 → 봉 위치 (`tToFi`)

`priceTimes()`가 주는 `_times`(오름차순 `YYYY-MM-DD` 배열)에서 이진탐색한다.

| 경우 | 처리 |
|---|---|
| 정확히 일치 | 그 인덱스 |
| 두 봉 사이 | 앞뒤 봉 사이를 **선형 보간**한 소수 인덱스(일봉에 그은 선을 주봉에서 볼 때) |
| 첫 봉보다 이전 | `0` 미만의 음수 인덱스로 외삽(창 밖 → 클립) |
| 마지막 봉 이후(미래) | 마지막 두 봉 간격으로 외삽(예측 구간에 찍은 점) |

`_times`가 없으면(붙여넣기·샘플 데이터) 그리기를 비활성한다 — 앵커할 날짜가 없기 때문.

### 2.2 봉 위치 ↔ 화면 좌표

`_mainGeo`(`fcDrawMainChart`가 매 프레임 갱신)의 `padX·histW·start·count·padTop·padBot·ch·loV·hiV·log`를 그대로 쓴다. 지표 작도(`_drawEvidence`)와 같은 좌표계이므로 정합이 보장된다.

- `fiToX(fi)` = `padX + (fi - start) / (count - 1) * histW`
- `pToY(p)` = 기존 `toY`와 동일(로그 인지)
- **역변환 신설**: `xToFi(x)`, `yToP(y)` — 클릭 지점을 앵커로 되돌릴 때 필요. `yToP`는 `g.log`면 `exp` 경유.

## 3. 파일 · 레이어

`forge-draw.js`가 이미 3,400줄이라 여기 넣지 않고 **새 파일 `forge-tools.js`**로 분리한다. 로드 순서: `core → state → ui → draw → tools → app`.

캔버스 `#fcDraws`를 hero에 추가한다(`pointer-events:none`, 지표 레이어 위). **포인터 이벤트는 종전대로 `#fcMainChart`만 받고**, tools에는 히트테스트만 물어본다. 새 캔버스가 이벤트를 받으면 기존 팬·줌이 깨진다.

### 3.1 공개 인터페이스

`forge-tools.js`가 전역으로 내보내는 것(다른 파일이 쓰는 접점):

- `drawsRender()` — `#fcDraws`에 현재 문서의 그림 전부 그리기. `fcDrawMainChart` 끝에서 호출.
- `drawsHitTest(cx, cy)` → `null | {kind:"handle"|"body", id, which}` — 포인터 분기용.
- `drawsPointerDown(e, cx, cy)` → `boolean` — 처리했으면 `true`(호출부는 기존 팬을 시작하지 않음).
- `drawsPointerMove(e, cx, cy)` / `drawsPointerUp(e)` — 드래그 진행·종료.
- `drawsKey(e)` → `boolean` — Esc/Del 처리 여부.
- `drawsArm(type)` / `drawsMagnet(on)` / `drawsClear()` — 툴바용.

## 4. 포인터 우선순위

현재 `forge-app.js:1137`의 `pointerdown`은 `y축 스트립 → 시간축 스트립 → 플롯 팬` 순으로 분기한다. 그 앞에 두 줄만 끼운다.

```
1. y축 스트립(cx > plotRight)        → 종전 yscale (도구 활성 중에도 축 조작 유지)
2. 시간축 스트립(cy > ch - padBot)   → 종전 xscale
3. drawsPointerDown() 이 true 반환   → 그리기/이동/끝점 조정이 가져감
4. 그 외                             → 종전 플롯 팬
```

`drawsPointerDown` 내부 판정 순서:

1. 도구가 armed → 새 그림 시작
2. 선택된 그림의 끝점 핸들 ±6px → 끝점 드래그
3. 아무 그림 본체 ±5px → 선택 + 통째 이동
4. 해당 없음 → `false`(팬으로 넘김)

임계값은 기존 관례를 따른다(엣지 끝점 재부착 6px·노드 드래그 4px). **그림이 0개이고 도구가 꺼져 있으면 `drawsPointerDown`은 즉시 `false`** — 기존 동작과 완전히 동일하다.

키 처리는 `forge-app.js`의 기존 전역 `keydown` 핸들러 맨 앞에서 `drawsKey(e)`를 먼저 호출하고, `true`를 반환하면 그 자리에서 멈춘다(기존 단축키로 흘리지 않는다).

- `Esc` — armed 도구가 있으면 도구 해제, 없으면 선택 해제
- `Del`/`Backspace` — 선택된 그림 삭제

입력 필드(`input`·`textarea`·`contenteditable`)에 포커스가 있으면 `drawsKey`는 즉시 `false`를 반환한다.

## 5. 도구 4종

| 도구 | type | 앵커 | 표시 |
|---|---|---|---|
| 추세선 | `trend` | a, b | 선 + 기울기 `+0.36%/봉` |
| 평행채널 | `channel` | a, b, c(폭) | 기준선 + 평행선 + 반투명 채우기 |
| 등락폭 재기 | `range` | a, b | 박스 + `Δ +56.5 · +19.6%` |
| 기간 재기 | `period` | a, b | 박스 + `104봉 · 152일` |

`range`와 `period`는 박스 렌더를 공유하고 라벨 문구만 다르다.

`channel`은 점 3개를 독립 저장하면 평행이 깨지므로 **기준선(a,b) + 가격 오프셋 하나**로 저장한다:

```js
{ id, type:"channel", a:{t,p}, b:{t,p}, off: 12.4 }   // off = 기준선에서 평행선까지의 가격 차
```

세 번째 점을 찍을 때 그 점에서 기준선까지의 **수직 가격 차**를 `off`로 환산한다. 렌더 시 평행선은 기준선의 각 끝점에 `off`를 더해 그린다.

색은 도구별 고정(추세=골드, 채널=블루, 등락=방향색, 기간=중립). 스타일 편집은 범위 밖.

## 6. 마그넷

도구가 아니라 **모디파이어**다. 켜면 점을 찍을 때 커서가 가리키는 봉의 시·고·저·종 네 값 중 **화면상 8px 이내로 가장 가까운 값**에 흡착한다. 없으면 흡착하지 않는다. 고점·저점을 정확히 집는 것이 목적이다.

OHLC는 `priceOHLC()`에서 읽는다. 캔들이 없는(종가 전용) 데이터에서는 종가에만 흡착한다.

## 7. 툴바

차트 헤더 우측(패널 접기 옆)에 **`✏ 도구 ▾` 버튼 하나**. 누르면 팝오버에 도구 4개 + 마그넷 토글 + `전체 지우기`.

기존 `.chart-pop` 패턴을 재사용한다. **좌측 세로 레일은 채택하지 않는다** — 시연 HUD(`.play-hud`)가 `position:fixed; left:12px; top:66px; z-index:95`로 앉아 있어, 패널 접기 버튼이 가려졌던 것과 같은 사고가 난다.

## 8. 저장

`dc.draws` 배열로 포지 문서에 실린다.

- `serializeActive`가 문서를 통째로 POST하므로 배열을 얹기만 하면 서버에 저장된다
- `loadDoc`에서 `dc.draws`를 메모리로 복원(없으면 `[]`)
- 변경 시 `markDirty()`(디바운스 자동저장)
- 그림 하나가 200바이트 남짓이라 128KB POST 상한과 무관

## 9. 검증

**단위테스트(`node --test`)** — 좌표 변환과 히트테스트를 순수 함수로 분리해 고정한다. 이들은 DOM에 의존하지 않으므로 테스트 가능하다.

1. `tToFi`: 정확 일치 / 두 봉 사이 보간 / 첫 봉 이전 / 마지막 봉 이후 외삽 / 빈 배열
2. `segDist`(점–선분 거리): 선분 위·수직 거리·끝점 너머
3. `channelOffset` 왕복: 앵커 → 오프셋 → 앵커 복원

**헤드리스 실화면**
4. 일봉에서 추세선을 긋고 **주봉으로 전환 → 같은 날짜·가격 위치 유지**(화면 좌표를 숫자로 대조)
5. **로그↔선형 전환** 시 앵커 가격이 그대로인지
6. 줌·스크롤 후에도 따라오는지
7. **무회귀**: 그림 0개·도구 꺼짐일 때 팬·줌·축 드래그가 종전과 동일

**규율** — 라이브 검증은 읽기 경로만 쓴다(`loadTicker`·`_addTickerDoc` 금지). 작도 변경이므로 **스크린샷 육안 대조까지** 한다(픽셀 수 비교로 끝내지 않는다).

## 10. 범위 밖 (YAGNI)

- 되돌리기(Ctrl+Z) — Del로 지우고 다시 그리면 된다
- 색·굵기 스타일 편집 — 도구별 고정색으로 시작
- 피보나치 도구 — 이미 지표(`fib`)로 있다
- 텍스트 메모·화살표·수평선 — 요청 범위 밖
- 그림의 다중 선택·복제·잠금
- 모바일 터치 그리기 — 데스크톱 우선(모바일은 도구 버튼 숨김)
