## Global Constraints

P0 플랜의 Global Constraints 전부 + 아래.

- 엔진 파일 수정 금지. 호출 레시피는 PC `_computeTf`(forge-app.js L1731~1756)와 동일 형태:
  `data={price:closes, candle:[{o,h,l,c}], n}` · `ForgeCore.run(graph, data, {futW, timeframe, driftWeights})` ·
  확률 = `ForgeCore.aggUpProb(res.prediction)` · 지평 = 일 60 / 주 52 / 월 12 · timeframe = "일봉"/"주봉"/"월봉".
- 분석 전 예측 노출 금지(지침서 §5). 기본 분석 결과에 "채점하지 않아요" 고지.
- 시세·판정 표시값은 전부 실데이터·실엔진 — 프로토의 T 가격·등락(더미) 사용 금지(이름·심볼만 승계).

## 엔진 브리지 계약 (이 플랜의 핵심 산출)

```js
MS.engine.analyze(req, onStep) → Promise<Report>
// req = { symbol, tfKo:'일'|'주'|'월', tier:'basic', candles:[{o,h,l,c,v}] }  (P2: deep/custom·weights)
// onStep({ i, total, id, name, group, bias, strength, text })  — 지표 1개 실계산 완료마다(연출 동기화용)
// Report = {
//   tier, symbol, tfKo, at,
//   verdict: { dir:'up'|'down'|'neutral', prob, target, rangeLo, rangeHi, invalid, score,
//              agree, totalInd, regime },
//   indicators: [ { id, name, group, bias, strength, text } ],   // basic 5
//   prediction: { path, lo, hi, counter, anchor, futW },          // 엔진 원출력 통과
//   engineVersion }
// 그룹: t추세 m모멘텀 v변동성 q거래량 s구조 (틱바 색과 짝, dissection/01 §3-3 GRP)
```

basic 5종(엔진 Lv1 = 프로토 IND 앞 5와 동일 구성): ma(t)·macd(m)·rsi(m)·bollinger(v)·volume(q).
그래프 노드: `[{id:'n_ma',kind:'block',blockType:'ma',params:{}},…,{id:'n_vol',blockType:'volume',series:volumes}]`, edges [] —
run()은 노드 존재로 드리프트·컨플루언스를 계산하고 sigSrc는 data.price 폴백(코어 L2005).
