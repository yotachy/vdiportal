# 머니스쿱 모바일 P2 — 3티어 격차 · 구현 계획서

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 기본·심화·전문 세 단계가 실제로 다르게 보이고, 그 차이가 **정직하게** 설명되는 상태를 만든다.

**Architecture:** 새 프레임워크 없음. 티어 차이를 **선언(데이터)으로 빼고 렌더러는 하나로 유지**한다 — 블록 3/8/9 는 세 벌의 화면이 아니라 같은 렌더러가 다른 목록을 받는 것이다. 가중치는 엔진이 이미 받는 인자(`opts.driftWeights`)를 채우는 일이지 엔진 개조가 아니다.

**Tech Stack:** 바닐라 ES5(`www/**`) · ESM 노드 테스트(`test/**`) · PHP 8(지갑 원장) · Capacitor(Android)

**Spec:** `map/docs/superpowers/specs/2026-08-17-moneyscoop-mobile-p2-tier-gap.md`

**참조(단일 출처):** 화면별 구성·문구 원문은 `map/mobile/docs/DESIGN-INVENTORY.md` §1. 티어 실측은 `map/backtest/tier-report.json`.

## Global Constraints

- **`www/**` 는 ES5.** `var`/`function` 만. `test/**` 는 ESM.
- **빌드 도구·외부 라이브러리 금지.** `www/index.html` 의 `<script src>` 순서가 의미를 갖는다 — 새 파일은 소비자보다 **앞**에.
- **사용자 가시 문자열은 `www/strings.js` 단일 출처.** 화면 소스에 리터럴 금지. 지표명(`IND`)은 영어 유지.
- **색은 `var(--토큰)` 만.** 좌측 세로 컬러 라인 절대 금지. 엘리베이션 그림자 없음.
- **엔진(`forge-core.js`·`forge-tools.js`)을 고치지 않는다.** P2 는 엔진에 **인자를 넘기는** 페이즈다. 엔진 수정이 필요하다고 판단되면 **멈추고 보고**할 것 — `./tests/run.sh engine` 이 PC 쪽과 함께 걸린다.
- **차트 그리기 방식을 바꾸지 않는다.** `draw-layers.js`·`draw-panels.js`·`chart-legend.js` 는 **호출 여부만** 바뀐다. 파일 내부를 고쳐야 한다고 판단되면 멈추고 보고.
- **관문:** `cd map && ./tests/run.sh` 전부 통과. 태스크마다 돌리고, 실패한 채로 커밋하지 않는다.
- **지갑 서버를 건드리는 태스크(Task 2)는 `./tests/run.sh concurrency` 를 추가로 돌린다** — 느려서 `all` 에 안 끼는, 사람이 기억해서 불러야 하는 유일한 관문이다(map/CLAUDE.md §④).
- **커밋 + 푸시 한 세트.** `mobile-p1-design` 은 upstream 이 걸려 있다. 모바일은 배포가 아니라 푸시가 짝이다.
- **P3·P4·P5 범위 밖:** 예측 결과 기록·재열람(21a)·내 기록(20b)·알림(20c) / 광고 진입점 확장 / 영어·반응형 다단.

### 판정

**R1 — 스캔 무료화는 서버 원장에 닿는다. 클라이언트 상수만으로 끝나지 않는다.**
`wallet-lib.php:22` `w_costs()` 가 **정본**이고(그 파일이 스스로 "서버가 정본이다. 클라이언트의 `MSWallet.COSTS` 는 미리보기 표시용일 뿐이다"라고 적어놨다), 클라이언트만 0 으로 바꾸면 서버는 계속 2 를 받는다. 따라서:
- `./tests/run.sh concurrency` 를 Task 2 에서 반드시 돌린다.
- 배포 시 `wallet-lib.php` · `wallet-api.php` · `wallet-ssv.php` **3종 동반**(하나만 올리면 `Call to undefined` 500 이 난다).
- **가격을 지우지 말고 0 으로 둔다.** `w_costs()` 에서 `"scan"` 키를 아예 빼면 이미 설치된 구버전 앱의 `spend("scan")` 이 `unknown-runtype` 으로 막혀 **스캔이 안 된다.** 0 이면 구버전도 무료로 동작한다.
- 부수 확인: 환불 경로가 `delta` 로 등급을 복구하는데(`wallet-lib.php:571`) 그 전제가 "가격이 서로 다르다"이다. `{full:3, custom:5, slot:1, scan:0}` 은 여전히 전부 다르다 — 기존 테스트가 이 전제를 지킨다. 단 **옛 scan 지출(delta 2)은 이제 어느 가격과도 안 맞는다** → `tier` 없이 삭제 경로로 떨어진다. scan 은 `w_entitled_types()` 에 없어 `runs` 행이 애초에 없으므로 무해하다. 이 사실을 코드 주석으로 남긴다.
*틀렸을 때 비용:* 서버가 계속 2 를 받아 무료화가 거짓말이 된다. 반드시 실측으로 확인할 것.

**R2 — 19a 와 8b 를 한 파일에 두지 않는다.**
규칙이 정반대다(19a=캐시로 빨리 끝나면 빨리 끝냄 / 8b=3초 끝까지 재생). 한 컴포넌트에 `mode` 플래그를 넣는 순간 둘 중 하나의 규칙이 조용히 다른 쪽에 샌다. 공유해도 되는 것은 빗 그래프 **그리기 함수**뿐이고 타이밍 정책은 공유하지 않는다.
*틀렸을 때 비용:* 분석 진행 화면이 일부러 느려지거나(사용자에게 거짓 대기), 축하 연출이 0.3초에 끝나 아무도 못 본다.

**R3 — 테스트 본문을 이 계획서가 받아쓰게 하지 않는다.**
P1 의 리뷰 판정 중 **여섯 건**(R2·D·E·F·G·P·L)이 *계획서가 시킨 테스트 코드의 결함*이었다 — 정규식 열거가 상상한 모양만 잡았다. 이 계획서는 각 관문에 대해 **① 단정할 성질 ② 통과하면 안 되는 구체적 우회 형태 ③ 변이 증명 의무**만 지정하고, 정규식은 구현자가 쓴다. 관문마다 **"이 형태를 실제로 주입해 빨갛게 만들고 원복했다"**를 보고서에 적지 않으면 그 태스크는 미완이다.

## Task 1: C1 — 타이포 3축 강제 관문 + 하드코딩 정리

**왜 먼저인가:** P1 성공 기준 ①이 부분 충족으로 남은 이유는 하드코딩 55건 자체가 아니라 **그것을 막는 관문이 없다**는 것이다. P2 는 화면을 여섯 개 이상 새로 그린다 — 관문 없이 시작하면 그 헐거움이 화면 수만큼 복제된다.

**Files:** Modify `map/mobile/test/style-tokens.test.mjs` · `map/mobile/www/style.css`

**Interfaces:** Produces — `font-weight`/`letter-spacing` 리터럴 0건 상태. Task 6~12 가 이 상태를 유지한다.

- [ ] **Step 1: 관문을 먼저 세운다(빨갛게).** `font-size` 관문과 같은 자리에 `font-weight`·`letter-spacing` 축을 추가한다. 현재 43건·12건이 걸려 **반드시 빨개야 한다** — 처음부터 초록이면 관문이 아무것도 안 보는 것이다.
  - 통과하면 안 되는 형태(P1 판정 X 의 잔여와 같은 계열): `font:` 단축 선언 안의 무게 · `calc()` 로 감싼 값 · 줄당 두 번째 선언(`/g` 누락). 셋을 실제로 주입해 확인할 것.
  - **예외는 주석 달린 목록으로만.** `@font-face` 블록의 `font-weight:100 900` 은 역할 토큰이 아니라 가변축 선언이다 — 목록에 사유와 함께 넣는다.
- [ ] **Step 2: 43 + 12 건을 역할 토큰으로 옮긴다.** 기존 값이 역할과 다르면(예: `.wl-brand` 700/−.01em vs `--fs-section` 역할 800/−0.03em) **역할 쪽으로 맞춘다** — 시안이 그 역할에 준 값이 정본이다. 값이 눈에 띄게 달라지는 항목은 보고서에 나열한다.
- [ ] **Step 3: C2·C3 를 같이 접는다.** `ALLOWED_LATIN` 의 `"v"`·`"ID"` 를 사용처가 있는 검사로 좁히거나 사유 주석을 정확히 하고, `readings.js` `PATTERN_NAME` 영문 폴백에 "왜 번역 대상이 아닌가" 주석을 단다.
- [ ] **Step 4: 관문 통과 확인.** `cd map && ./tests/run.sh mobile` → 전체 `./tests/run.sh`.

## Task 2: 스캔 무료화 (D4) — 서버 원장 + 클라 + 가격표 문구

**⚠ 이 태스크만 서버 원장에 닿는다 (판정 R1).**

- [ ] **Step 1: 실패하는 테스트.** ① 서버 `w_costs()["scan"] === 0` ② 클라 `MSWallet.COSTS.scan === 0` ③ **`watchlist.js` 에 `spend("scan"` 호출이 없다** ④ 지갑 "쓰는 곳"·온보딩 가격표에 스캔이 **무료로** 표시된다(숫자 아님) ⑤ 네 가격이 여전히 서로 다르다(환불 등급 복구 전제).

## Task 3: 진실 규칙 관문 (§2 R1~R4)

**왜 화면보다 먼저인가:** 시안 파일에 `64%`·`58%`·"2%p 만 오릅니다"가 그대로 남아 있다. 화면을 먼저 그리면 다음 사람이 그 숫자를 그대로 옮긴다. **이 페이즈의 산물은 화면이 아니라 화면이 할 수 있는 말의 경계다.**

**Files:** Create `map/mobile/test/truth-rules.test.mjs`
